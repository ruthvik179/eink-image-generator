# E-Ink Image Converter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished, directly double-clickable `ereader-image-converter.html` that crops and converts local raster images to exact e-reader screen dimensions entirely offline.

**Architecture:** `web/image-processing.js` is a dependency-free UMD-style module containing presets, validation, crop geometry, and deterministic pixel algorithms that run unchanged in Node tests and the browser. `ereader-image-converter.html` embeds a generated byte-for-byte copy of that module plus app-specific DOM/canvas code and CSS, while `scripts/sync-standalone.mjs` updates or verifies the embedded copy. The browser decodes and crops with canvas, then applies the tested pixel pipeline at preview or export dimensions.

**Tech Stack:** HTML5, CSS, browser Canvas and File APIs, plain JavaScript, Node.js 24 built-in test runner, Playwright Core for the direct-file browser smoke test.

## Global Constraints

- The user launches `ereader-image-converter.html` directly from File Explorer.
- The delivered page has no network calls, server requirement, package installation, analytics, or runtime dependencies.
- CSS, browser application JavaScript, and a generated copy of `web/image-processing.js` are embedded in the single HTML file.
- Processing and export occur locally; output is a full-resolution PNG with no intentionally added metadata.
- Custom dimensions are positive whole numbers from 1 through 10,000.
- Export reruns the pipeline at exact target dimensions and never enlarges a preview.
- The existing Java EPUB extraction application remains unchanged.
- Every production function is introduced through a failing automated test, then the minimal implementation is added and the test is rerun.
- Preset source comments include manufacturer product/support URLs where available; multiple recognizable model names may share one dimension preset.
- Maven is unavailable in the execution environment, so the unchanged Java baseline cannot be rebuilt here; all new frontend checks use Node and an installed Chromium-family browser.
